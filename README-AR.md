# حزمة نقل القنوات والوظائف دون التصميم

الوجهة المطلوبة: https://almoghani-net-22.lovable.app/iptv.html

## المحتوى
- catalogs/channels.json: 316 قناة عامة، مع الاسم والقسم ورابط التشغيل وبيانات يوتيوب.
- catalogs/channels-direct.m3u: 228 قناة برابط بث مباشر.
- catalogs/channels-youtube.m3u: 88 قناة أخرى بروابط يوتيوب؛ لا تعمل في كل تطبيقات IPTV.
- catalogs/movies.json: 50 فيلمًا من القائمة العامة.
- catalogs/series.json: 9 مسلسلات مع بيانات الحلقات؛ صور الحلقات مراجع يوتيوب وليست تصميم الموقع.
- reference/: ملفات منطق الموقع بصيغة TypeScript كمرجع للدمج، تشمل البحث والتشغيل والأعضاء والإدارة والدردشة والصوت، دون صفحات الواجهة أو CSS.

## طريقة النقل في Lovable
افتح مشروع الموقع الوجهة وارفع هذه الحزمة مع الطلب أدناه. يجب دمج البيانات وربط الوظائف بأزرار الموقع الموجودة، لا نسخ الملفات فوق المشروع مباشرة.

## حدود الحزمة
ليست موقعًا جاهزًا للتشغيل ولا نسخة كاملة من البيانات المحفوظة. لا تحتوي حسابات الأعضاء أو الإعدادات المحفوظة أو كلمات المرور أو أسرار الخدمات أو بيانات الاشتراك الخاص بسمارتر. هذه تحتاج تهيئة آمنة في مشروع الوجهة. ملفات reference قد تشير إلى صور أو ملفات أو خدمات مستبعدة؛ هي مرجع فقط ويجب تكييفها مع مشروع الوجهة قبل الاستيراد، مع إنشاء ملفات الربط والحماية والجداول المطلوبة داخله. لا تنقل حساب المالك القديم أو صلاحياته إلى المشروع الجديد تلقائيًا.

حافظ على حماية الأعضاء والمالك والروابط الخاصة. لا تنشر أي كلمة مرور أو بيانات اشتراك داخل ملفات الموقع. لا تستبدل تصميم الوجهة أو ألوانها أو خطوطها أو صور خلفياتها. روابط القنوات من الكتالوج الحالي، ولم يعاد اختبار توفر كل بث خلال التصدير.
